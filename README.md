# J. Carlos Repair Shop — sitio web

Sitio informativo y adaptable a dispositivos móviles para un taller de mantenimiento de motocicletas.

## Archivos

- `index.html`: estructura, textos, servicios y enlaces de contacto.
- `style.css`: estilos, diseño adaptable y animaciones.
- `script.js`: menú móvil, animaciones al desplazarse y año automático del pie de página.
- `logo.png`: logotipo proporcionado, recortado para uso web.
- `favicon.svg`: icono de la pestaña del navegador.

## Cómo abrirlo

Abre `index.html` en un navegador. No necesita instalación ni proceso de compilación.
